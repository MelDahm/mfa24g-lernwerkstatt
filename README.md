# Lernwerkstatt MFA24G

Interaktive Lerntools für die MFA-Ausbildung.

## Inhalte
- **Prostata_Lerntool** (`index.html`): Quiz, Lückentext, Zuordnung, Karteikarten
- **Lerntool_Prostata** (`Lerntool_Prostata_MFA.html`): Grundlagen, BPH, Prostatakarzinom, Vergleich
- **Praesentation_Prostata** (`Praesentation_Prostata_MFA.html`): 20 Folien zur Vorlesung
- **Frueherkennung_Prostatakrebs**: PSA, Früherkennungsuntersuchung, Patientenfaq
- **Wiederholungstool** (`Wiederholung/Wiederholungstool_MFA24G.html`): Quiz für LF01, LF03, LF06, LF08 und Zwischenprüfung – mit Fortschrittsanzeige, Tagesfrage, Statistik und lokal gespeicherten Ergebnissen

## Anleitung
Öffnen Sie die HTML-Dateien direkt im Browser – alle Tools sind eigenständige Dateien ohne Internetverbindung.

Online-Version: <https://meldahm.github.io/mfa24g-lernwerkstatt/>
