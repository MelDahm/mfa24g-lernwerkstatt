# Lernwerkstatt MFA24G

Interaktive Lerntools für die MFA-Ausbildung.

## Inhalte
- **Prostata_Lerntool**: Quiz, Lückentext, Zuordnung, Karteikarten
- **Lerntool_Prostata**: Grundlagen, BPH, Prostatakarzinom, Vergleich
- **Praesentation_Prostata**: 20 Folien zur Vorlesung

## Anleitung
Öffnen Sie die HTML-Dateien direkt im Browser.
